# Exact pins, not ranges.
#
# `fastapi>=0.100` means the image you build today and the image you build
# tomorrow contain different code with the same tag. That makes an SBOM a
# snapshot of one build rather than a description of the artifact, and it means
# a scan result cannot be trusted five minutes later.
#
# Hash pinning is added in a later stage — pins stop drift, hashes stop
# substitution.
fastapi==0.141.1
uvicorn==0.42.0
pydantic==2.13.0

# TRANSITIVE DEPENDENCY, PINNED DELIBERATELY.
#
# starlette is pulled in by fastapi, not chosen by this app. Two HIGH advisories
# (GHSA-82w8-qh3p-5jfq, GHSA-wqp7-x3pw-xc5r) affected 0.49.3, which is what
# fastapi resolved to on its own.
#
# This is the shape of most real supply-chain findings: the vulnerable package
# is one you never named. fastapi 0.141.1 requires only `starlette>=0.46.0`
# with no upper bound, so a patched version is reachable — but nothing would
# have pulled it in without an explicit pin here.
#
# Pinning a transitive dependency is a maintenance cost: it must be reviewed
# when fastapi changes its requirements, or it will silently hold back an
# upgrade. That cost is the reason to record WHY the pin exists.
starlette==1.6.0
